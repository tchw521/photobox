# 光影相册 PhotoBox

一套 Python（Flet / Flutter 渲染）代码，同时产出 **Android APK** 与 **Windows EXE** 的照片管理工具。
界面风格：深紫渐变 + 半透明玻璃卡片；左侧栏 = 图集（相册），右侧主区 = 照片（宫格 / 列表双视图）。

**左侧相册分类栏常驻显示，宽度恒为界面的 1/5（20%）**，右侧内容区独立排版，绝不重叠、不遮挡图片。

| 界面宽度 | 侧栏宽度 | 占比 | 内容区 |
|---|---|---|---|
| 1180px | 236px | 20.0% | 944px |
| 768px | 154px | 20.0% | 614px |
| 500px（手机） | 100px | 20.0% | 400px |

宽度带上下限（88px ~ 240px）保证小屏也能读；宫格列数按**扣除侧栏后的剩余宽度**计算，
点左上角 ☰ 可临时折叠侧栏换取全屏看图。

## 安卓机型适配

**照片目录覆盖**（54 个候选，自动去重 + 过滤空目录）：

| 类别 | 目录 |
|---|---|
| 相机 | `DCIM`、`DCIM/Camera`、`Camera` |
| 截图与社交 | `Pictures`、`Pictures/Screenshots`、`Pictures/WeiXin`、`Pictures/QQ`、`Pictures/Weibo` |
| 微信/QQ 深层 | `Tencent/MicroMsg`、`Tencent/QQfile_recv` |
| 下载 | `Download`、`Downloads` |
| 厂商定制 | `MIUI/Gallery/cloud`（小米云相册）、`Huawei/MagazineUnlock`（杂志锁屏）、`oppo/camera`、`vivo/Camera` |
| 应用媒体 | `Android/media`、`Movies` |

根目录同时探测 `/storage/emulated/0`、`/sdcard`、`/mnt/sdcard`，软链自动去重（realpath 比对）。

**屏幕适配**（实测 iframe 精确宽度）：

| 屏宽 | 侧栏 | 占比 | 宫格列数 | 卡片宽度 |
|---|---|---|---|---|
| 360px（小屏机） | 72px | 20% | 3 | 87px |
| 390px（iPhone 标准 / 多数安卓） | 78px | 20% | 3 | 93px |
| 412px（Pixel） | 82px | 20% | 3 | 99px |
| 430px（Pro Max / 大屏安卓） | 86px | 20% | 3 | 104px |
| 600px（折叠屏外屏 / 平板） | 120px | 20% | 5 | 86px |

沉浸式布局用 `env(safe-area-inset-*)` 避开刘海与底部手势条；触摸目标不小于 44dp。

## 交互说明

**图库长按 → 多选操作条**

长按任意照片进入多选（宫格、列表、时间线三种视图都支持），首次长按会提示「已进入多选，可继续点选更多」，
之后轻点其他照片即可继续加选。底部出现两行操作条：

| 操作 | 行为 |
|---|---|
| 收藏 | 批量加入 / 取消收藏（已全收藏时自动转为取消） |
| 移动 | 底部弹出相册列表，选中即批量移动；可新建文件夹、可切复制模式 |
| 重命名 | 仅单选时可用，保留扩展名，索引与收藏同步更新 |
| 删除 | 先移入回收站，确认后执行，可随时还原 |

**侧边栏相册名**

- 去掉所有图标，只保留名称气泡与数量
- 气泡视口宽度锁死为两字（34px），静止时看到的就是前两个字
- 名称超过两字时，完整名在气泡内左右滚动（跑马灯）露出余下部分
- 悬停 / 长按显示完整名称

**卡片页与设置页不显示左侧相册栏**（分类动作在卡片页底部相册栏完成，设置页需要整宽），
内容区自动占满 100% 宽度。

## 快速开始

```bash
pip install -r requirements.txt
python main.py          # 本地以桌面窗口运行（调试最快）
```

`python main.py` 会调用 `flet run` 打开一个本地窗口，改动代码即时可见。

## 构建 Android APK

```bash
bash build_apk.sh
```

脚本会先做环境自检（Python 版本 / JDK / 磁盘空间），不满足会直接给出提示。

环境要求：**可访问外网的机器**（需从 Google / GitHub 下载 Flutter SDK 与 Android SDK）、JDK 17+、Python 3.10+、8GB 空闲磁盘。
首次构建 20~40 分钟。产物：`build/apk/光影相册.apk`

脚本已内置国内镜像自动探测，会依次尝试并在终端打印每个镜像的连通结果：

| 用途 | 镜像 |
|---|---|
| Flutter SDK | 清华 `mirrors.tuna.tsinghua.edu.cn/flutter`、阿里 `mirrors.aliyun.com/flutter`、中科大 `mirrors.ustc.edu.cn/flutter` |
| Pub（Dart 包） | 清华 `dart-pub`、阿里 `pub`、中科大 `dart-pub` |
| Gradle / Maven / Android SDK | 腾讯 `mirrors.cloud.tencent.com` |

**已知限制**：若构建环境前面挂了网络代理白名单，且未放行上述域名，会看到
`403 Request denied / policy_default_denied`——这是代理策略拦截，不是脚本或配置问题，
换一台能正常联网的机器运行即可。

**权限说明**：Android 13+ 需要「照片和视频」权限才能读取公共目录；要支持清理 / 移入回收站，还需「所有文件访问权限」。
首次启动请在系统弹窗中授权，或在 设置 → 应用 → 光影相册 → 权限 中手动打开。若设备未提供该权限，可在设置页手动输入目录路径作为兜底方案。

## 构建 Windows EXE

双击 `build_windows.bat`（或在命令行执行）。

环境要求：Windows 10/11、Python 3.10+、Visual Studio 2022（勾选「使用 C++ 的桌面开发」）。
首次运行会自动下载 Flutter SDK（约 1.5 GB）。
产物：`build/windows/` 下的 `.exe`（可直接拷贝运行，无需安装 Python）

## 常见问题

- **扫描到 0 张照片**：检查设置页的扫描目录是否存在；Android 上多为权限未授予。
- **缩略图加载慢**：首次进入会后台生成，之后走缓存；设置页可调整缩略图尺寸（160~640px）。
- **APK 体积**：约 40~60 MB（含 Python 运行时与 Flutter 引擎）。
- **签名**：默认 debug 签名；正式分发请用 `--android-signing-key-store` 指定自己的 keystore。
